Contributing to Jaza
Thank you for considering a contribution.
Good first contributions
Clarify setup or troubleshooting instructions.
Report a reproducible issue with Windows and PowerShell version details.
Improve input validation and error handling.
Add tests or compatibility notes for supported Windows versions.
Before opening a pull request
Open an issue for substantial changes so the scope can be discussed.
Keep changes focused and explain the problem they solve.
Do not add telemetry, external network requests, or collection of personal data.
Do not add commands that modify system settings, firewall rules, services, or running processes.
Test locally and include the PowerShell and Windows versions in the pull request description.
Pull request checklist
[ ] The change has a clear purpose.
[ ] Documentation is updated where needed.
[ ] No credentials, tokens, private files, or personal data are included.
[ ] Local checks remain read-only.
[ ] Any limitations are documented.
